شاکەل - وەشانی سەرەتایی بە سێرڤەری ناوخۆیی

1) لە Termux بنووسە:
   pkg update -y
   pkg install python -y
   pip install -r requirements.txt

2) لە ناو ئەم بوخچەیە:
   python app.py

3) لە Chrome بکەرەوە:
   http://127.0.0.1:5000/setup

4) لە پەڕەی setup ناوی بەکارهێنەری بەڕێوەبەر و وشەی نهێنی دابنێ.
   وشەی نهێنی لە کۆدی HTMLدا نییە؛ hash دەکرێت و لە SQLite هەڵدەگیرێت.

5) دواتر بەڕێوەبەر دەتوانێت یاری، هەواڵ و هەژماری یاریزان زیاد بکات.

گرنگ:
- ئەمە وەشانی تاقیکردنەوەیە و لەسەر هەمان مۆبایل/ناو تۆڕی ناوخۆیی کار دەکات.
- بۆ ئەوەی هەموو یاریزانەکان لە شوێنی جیاوازەوە هەمان زانیاری ببینن، پێویستە سێرڤەرێکی ئۆنلاین و HTTPS دابنرێت.
- پێش بڵاوکردنەوەی ئۆنلاین، SHAKAL_SECRET بگۆڕە بۆ وشەیەکی نهێنیی درێژ و یەکتا.
- ئەم وەشانە هێشتا لۆگۆی وێنەیی و پشتگیرییەکانی وەک وێنەی یاریزان و ئاگادارکردنەوەی pushی تێدا نییە.
